# @sekizui/spinal

脊髓层的 Cordis 服务。这是**唯一**知道快模型存在的地方。

## 职责

- 持有弧库（`@sekizui/arc` 的弧声明，落盘、版本化）。
- 按窗口周期取一份快照（来自采样面），窗口内共享。
- 把弧投影成 state、渲染成问题，单飞发一次请求。
- 判决带 TTL 与连接代次进缓存，供传出层读取。
- 每次判断追加一行决策账本，可还原、可回放。

## 与外部的关系

三份薄接口是本层与外部的全部边界，实现都留给外部。目前只有采样面的两个类型（`SampleCatalog` / `Snapshot`）落地，意图汇与账本的类型是下一步：

| 接口     | 谁实现                     | 干什么                         |
| -------- | -------------------------- | ------------------------------ |
| 采样面   | nerve 一侧（如 minecraft） | 给出一份带代次的世界快照       |
| 意图汇   | nerve 一侧                 | 接收判决并执行                 |
| 决策账本 | 本包写，编排层读           | 还原"它当时看到什么、答了什么" |

## 状态

骨架。已具备服务注册、配置段与弧库加载；窗口采样、Jev 客户端、判决缓存与账本是下一步。
